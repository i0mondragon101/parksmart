# ParkSmart

A mobile-first web app that helps students find realistic campus parking options and reduce the time and stress of searching for parking before class.

## Features

- Enter a campus destination and view parking options
- Receive parking recommendations based on destination, current parking availability, and walking distance
- View current parking conditions and recent user reports
- Submit parking-condition updates
- Receive driving and walking directions
- Save class locations

## Tech Stack

- **Client**: React (mobile-first, Vite for local development)
- **API**: Express (Node.js)
- **Database**: Supabase

## Project Structure

```
/client/    # React mobile-first app (local dev: Vite)
/api/       # Express API (local dev: Node)
/supabase/  # SQL migrations + seeds
/docs/      # PRD, task list, site map, OpenAPI, deployment notes
```
